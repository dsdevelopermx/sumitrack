## Decisiones técnicas

**`material-icons-extended`:** Añadido para `Icons.Outlined.CloudDone` / `Cloud` según spec de historia. BOM-managed, sin versión explícita. R8 hace tree shaking en release.

**`flatMapLatest` sobre Room Flow:** Patrón óptimo para búsqueda reactiva — al cambiar `searchQuery`, el operador cancela el upstream anterior y suscribe al nuevo sin race conditions.

**`SharingStarted.WhileSubscribed(5_000)` en tests:** Requiere subscriber activo para iniciar upstream. Patrón correcto: `val job = launch { viewModel.clients.collect {} }; advanceUntilIdle()` antes de mutaciones en FakeDao.

**`SearchBar` M3 API (Compose BOM 2026.06.00):** La API usa un slot `inputField = { SearchBarDefaults.InputField(...) }` — diferente a versiones anteriores que recibían los parámetros directamente.

**`Locale.Builder()` en lugar de `Locale("es", "MX")`:** Constructor de dos strings marcado deprecated en Java. Replacement: `Locale.Builder().setLanguage("es").setRegion("MX").build()`.

## Problemas encontrados y soluciones

### 1. Tests ClientListViewModel — AssertionError expected:2 but was:0

`SharingStarted.WhileSubscribed(5_000)` no activa el upstream sin suscriptor. Tests leían `.value` directamente sin estar suscritos → siempre `emptyList()`.

**Fix:** Patrón con `launch { collect {} }` + `advanceUntilIdle()` antes de mutar el FakeDao.

### 2. Deprecation `Locale("es", "MX")`

Warning del compilador en `ClientCard.kt`. **Fix:** `Locale.Builder().setLanguage("es").setRegion("MX").build()`
