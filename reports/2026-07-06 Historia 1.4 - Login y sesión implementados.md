## Decisiones técnicas destacadas

### Converter de serialización cambiado
- El story file especificaba `com.jakewharton.retrofit2:retrofit2-kotlinx-serialization-converter:1.0.0`
- Este artifact no está disponible en Maven Central
- Se usó `com.squareup.retrofit2:converter-kotlinx-serialization:2.11.0` (oficial, incluido en Retrofit 2.11.0+)
- Import: `retrofit2.converter.kotlinx.serialization.asConverterFactory`

### AppNavHost — SessionState sealed class vs Boolean?
- El story file sugería `StateFlow<Boolean?>` (null=loading)
- Se implementó con `SessionState` sealed class (`Loading`, `LoggedIn`, `LoggedOut`) para mayor expresividad y seguridad de tipos
- La lógica es equivalente, pero más mantenible

### Logout reactivo sin navegación explícita
- `SettingsViewModel.onLogoutConfirm()` solo llama `sessionManager.clearToken()`
- `AppViewModel.sessionState` detecta el cambio vía DataStore flow
- `AppNavHost` tiene `LaunchedEffect(sessionState)` que navega a Login
- Sin acoplamiento entre SettingsViewModel y la navegación
