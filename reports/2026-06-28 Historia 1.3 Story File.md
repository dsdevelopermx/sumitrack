## Decisiones técnicas tomadas

| Decisión | Razón |
|---|---|
| KSP en lugar de kapt | Kotlin 2.x requiere KSP; kapt obsoleto con Compose |
| `ksp = "2.1.21-2.0.21"` | KSP version DEBE coincidir con Kotlin 2.1.21 |
| Room 2.8.4 (no 3.0) | AR-3 explícito: "No usar Room 3.0 (alpha)" |
| `exportSchema = true` | Permite auditoría de migraciones; detecta inconsistencias temprano |
| `BigDecimal` → `TEXT` SQLite | AR-17: precisión monetaria; `toPlainString()` evita notación científica |
| `Instant` → `Long` millis | minSdk=26 lo soporta nativamente; queries de rango de fechas eficientes |
| Solo LightColorScheme | Sin dark mode en v1 — la app es de campo |
| NavigationBar con popUpTo + saveState | Patrón M3 correcto; evita back stack infinito entre tabs |
| Stubs de pantallas vacíos | Permite compilación del NavGraph sin implementar lógica de negocio |
